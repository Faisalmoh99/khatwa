# كود ESP32 (الخطوة الجاية: الأحد 8 نوفمبر)

الكود يكتب لنفس المسارات اللي يكتب لها المحاكي (`docs/DATA_SCHEMA.md`). لو المحاكي شغّال مع التطبيق، الجهاز بيشتغل بدون ما نغيّر شي في التطبيق.

## التوصيل
| من | إلى | ملاحظة |
|---|---|---|
| حساسات القدم اليسرى (4) | GPIO 4 | OneWire، مقاومة 5.1kΩ بين السلك الأصفر و3.3V |
| حساسات القدم اليمنى (4) | GPIO 18 | نفس الشي |
| ضغط الكعب الأيسر / الأيمن | GPIO 34 / 35 | مقسم جهد مع 10kΩ إلى GND |
| LED أخضر / أحمر | GPIO 25 / 26 | عبر 220Ω |
| البازر | GPIO 27 | active |

## ترتيب العمل يوم الأحد
1. تعريف اللوحة في Arduino IDE (حزمة ESP32 من Espressif) وتشغيل مثال Blink.
2. حساس واحد على GPIO 4 وطباعة حرارته.
3. توصيل الأربعة وطباعة عناوينهم (ROM) ← نكتب جدول: أي عنوان = أي نقطة.
4. نفس الشي للقدم اليمنى.
5. قراءة حساسي الضغط ونحدد العتبات (واقف / نازل).
