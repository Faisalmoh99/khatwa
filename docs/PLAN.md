# خطة النسخة الأولى (تسليم السبت 14 نوفمبر)

## المبدأ
أقوى شي نعرضه للحكام (أطباء) هو **حلقة حقيقية تشتغل**: رجل على السجادة ← قراءة حقيقية ← قاعدة IWGDF ← تنبيه للمريض والعائلة والعيادة. أي ميزة شكلها قوي لكن ما يقيسها الجهاز تضرّنا قدامهم، فتطلع كـ «إصدار قادم» بوضوح.

## الميزات

### ندخلها (حقيقية، من بيانات الجهاز)
| الميزة | ملاحظة |
|---|---|
| خريطة حرارية حيّة 4 نقاط لكل قدم | من `live` في Firebase |
| شاشة «جهازي» | متصل/غير متصل، آخر قراءة، تعليمات الوقوف، حلقة تقدم أثناء الفحص |
| فحوصات الجودة | قدم وحدة، حركة، حرارة غير منطقية + سؤال القدم المبللة، خطأ وقوف، حساس معطّل |
| القاعدة: أخضر/أصفر/برتقالي | `rules.js`، فرق > 2.2° نفس النقطة ونفس القدم يومين متتاليين |
| الأحمر من بلاغ المريض | الفحص السريع (جرح/فقاعة) أو علامة خطر في المحادثة. مو من الحساسات |
| سلّم المتابعة | يوم بدون قياس: تذكير. يومين: العائلة. 3 أيام: العيادة |
| تنبيه العائلة | زر واتساب `wa.me` برسالة جاهزة |
| المحادثة (قوالب ثابتة) + صوت عربي | تصعّد ولا تخفّض ولا تشخّص |

| السجل والرسوم | من `scans` الحقيقية |
| خط أساس أول 7 أيام | للعرض فقط، مكتوب «فرضية» |
| تقرير الزيارة + QR + طباعة PDF | من البيانات الحقيقية |
| واجهة العيادة والعائلة وسجل التصعيد | المريض الحقيقي فوق، والبقية مكتوب عليهم «افتراضي» |
| وضع العرض: كل فحص = يوم | ضروري للفيديو: نوري قاعدة اليومين في دقيقتين. مكتوب على الشاشة |
| وضع المحاكاة (السيناريوهات + الأيام الثلاثين) | زر واضح، والشعار «بيانات محاكاة» |

| PWA: إضافة للشاشة الرئيسية | manifest + أيقونة + يفتح بدون نت (الواجهة فقط) |

### نؤجّلها (تطلع «إصدار قادم» بدون أرقام ولا منطق)
- التروية (PPG): ما عندنا حساس.
- خريطة الضغط وتنبيه الضغط المركّز: عندنا حساس واحد لكل كعب، للوقوف فقط.
- تحليل الصورة بالذكاء الاصطناعي: الصورة تنحفظ وتطلع في التقرير «للعيادة تشوفها»، بدون مؤشر ولا مستوى.
- إشعارات حقيقية (FCM/SMS/WhatsApp API)، OTP، أوقات الصلاة من API، ترقية TMP117.

### نحذفها من النموذج الحالي
- `SITES` بـ 8 نقاط لكل قدم ← 4. و`ZONES` الثلاث ← ضغط كعب واحد.
- كل نص فيه «16 حساس» أو «TMP117» أو «6 حساسات ضغط» أو «حساسا تروية» (في الدليل والوسادة والأسطورة).
- منزلق «مدة الضغط المسموحة» و«ضغط مركّز على منطقة» ومسار `heatPress` في `levelCore`.
- `lowPI` من `levelCore` (التروية ما تطلّع أحمر).
- «نتيجة تحليل الذكاء الاصطناعي» ومؤشر الاحمرار اللي يطلّع أحمر.
- كود Arduino المضمّن في الصفحة (TMP117 + TCA9548A + MAX30102 على GPIO 25/26، وهي أصلًا أرجل الضوء عندنا).
- البطارية الوهمية وحرارة الغرفة (ما عندنا حساس غرفة). مكانها «التغذية: USB».

## مخاطر لازم ننتبه لها
1. **ESP32 واحد بدون احتياط.** لو احترق يوم 10 توقف كل شي. اشتروا واحد ثاني الأحد (~30–40 ريال من أي محل إلكترونيات).
2. **زمن الفحص.** الحساس داخل أنبوب ستانلس بطيء. ممكن الاستقرار ياخذ أكثر من دقيقة. نقيسه الأربعاء، وما نكتب رقم قبل القياس.
3. **ساعة التسليم يوم 14 ما نعرفها.** لو كانت الصبح، الجمعة هي آخر يوم عمل فعلي.
4. **الباور بانك**: بعضها ينطفي لما السحب قليل. جرّبوه ساعة قبل الفيديو، أو استخدموا شاحن جدار.
