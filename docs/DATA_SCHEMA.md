# شكل البيانات (الإصدار 1، معتمد 7 نوفمبر 2026)

هذا العقد بين **ESP32** و**المحاكي** و**التطبيق**. أي تغيير هنا يتغيّر في الثلاثة مع بعض.

```
/devices/khatwa-01/
  status/        يكتبها الجهاز كل 10 ثواني (نبضة)
  live/          يكتبها الجهاز كل ثانية أثناء الوقوف، ومرة وحدة لما يرجع idle
  scans/<id>     قراءة كاملة واحدة لما يخلص الفحص بنجاح (push)
  events/<id>    أحداث من التطبيق: فحص سريع، علامة خطر، إقرار العائلة/العيادة
  calibration/   نتائج المعايرة (للتوثيق في README)
```

## ترتيب النقاط (ثابت في كل مكان)
| index | النقطة | id |
|---|---|---|
| 0 | الإبهام | hallux |
| 1 | رأس المشط الأول | mth1 |
| 2 | رأس المشط الخامس | mth5 |
| 3 | الكعب | heel |

`L` = القدم اليسرى (GPIO 4)، `R` = القدم اليمنى (GPIO 18). الفرق دائمًا `R − L` (موجب = اليمين أسخن).

## status
| الحقل | النوع | ملاحظة |
|---|---|---|
| online | bool | `true` وهو شغّال |
| lastSeen | ms (وقت السيرفر) | `{".sv":"timestamp"}` من ESP32 |
| firmware | string | مثل `"0.1.0"` أو `"sim-0.1.0"` |
| source | `"esp32"` \| `"sim"` | |
| rssi | int (اختياري) | قوة الواي فاي |

ESP32 ما يقدر يكتب «غير متصل» لما ينطفي، فالتطبيق يعتبره **غير متصل** إذا `lastSeen` أقدم من **60 ثانية**.

### قواعد مهمة
- **لا تكتب `null` داخل مصفوفة.** Firebase يحذف العناصر الفاضية ويرجع المصفوفة ككائن. الحساس المعطّل = `-127` (نفس قيمة مكتبة DallasTemperature).
- ESP32 **ما يكتب scan** إذا الوقوف غلط (قدم وحدة أو نزل قبل الانتهاء). يكتب `live.phase = "error"` بس.
- الحكم (أخضر/أصفر/برتقالي) يصير **في التطبيق** من `app/js/rules.js`، مو في الجهاز. الجهاز يقيس ويرسل فقط.

## الاستقرار (الجهاز والمحاكي بنفس المنطق)
- الوقوف: حساسي الكعب الاثنين فوق العتبة (تتحدد بعد التجربة، مبدئيًا ADC > 1800 للبدء و< 600 = نزل).
- الاستقرار: كل الحساسات الثمانية تغيّرها أقل من **0.1°م خلال آخر 5 ثواني**، وبعد 8 ثواني على الأقل.
- الحد الأقصى **90 ثانية**، بعدها يُكتب scan مع `stable: false` (التطبيق يرفضها ويطلب إعادة).

## events/<id> (يكتبها التطبيق)
| الحقل | ملاحظة |
|---|---|
| kind | `quickcheck` \| `redflag` \| `photo` \| `family_ack` \| `clinic_ack` \| `mode` |
| data | كائن حسب النوع، مثل `{skin:"wound", pain:true}` |
| day | مفتاح اليوم (`2026-11-12` أو `D3`) |
| ts | وقت السيرفر |

## calibration
```
calibration/
  calibratedAt: ms
  reference: "Beurer FT09"
  waterC: 36.4
  sensors/
    "28FF64A1B2C3D4E5": { slot: "L0", rawC: 36.1, offsetC: 0.3 }
```
القيم نفسها تُكتب كثوابت في كود ESP32 (`calibration.h`). المسار هذا للتوثيق ونتائج الاختبار.
